## ✨ Key Features & Architecture

1. **Luxury Obsidian & Champagne Gold Visual Aesthetic**:
   - Cormorant Garamond serif headings paired with clean Plus Jakarta Sans typography.
   - Ambient gold glow gradients and glassmorphism cards.
   - Micro-interactions, hover card lifts, and smooth scrolling.

2. **Curated Family Service Catalog**:
   - Filterable categories: Men's Grooming, Women's Styling, Hair Spa & Repair, Facials & Skin Radiance, Kids Haircuts, Bridal & Occasion Packages.
   - Transparent in-salon consultation pricing policy (no invented discounts).

3. **Official Salon Photo Kit & Live Dropzone**:
   - Details the 6 mandatory photo perspectives required for brand excellence (Storefront, Styling Chairs, Reclining Wash Basin, Private Skin Suite, Reception, Stylists in Action).
   - Allows clients/owners to drop local photos to preview them live on the website in real time.

4. **Interactive Appointment Builder**:
   - Multi-service selection with dynamic duration calculator.
   - Preferred time slot picker (Morning, Afternoon, Evening) and stylist preference.
   - Confetti celebration upon reservation preparation and pre-filled WhatsApp message generator.

5. **Direct Navigation & Maps Integration**:
   - Direct button to launch Google Maps driving route for Karimnagar visitors.

6. **Fully Mobile Responsive**:
   - Sticky mobile action bar with quick access to Maps, Booking, and Call.
   - Touch-optimized drawer menu and accessible modals (Esc key dismiss, backdrop blur).

- **Icons**: Lucide React (`lucide-react`)
- **Effects**: Canvas Confetti (`canvas-confetti`)
- **Build Tool**: Vite 8+
- **Deployment**: GitHub Actions (`deploy-pages@v4`) to GitHub Pages
